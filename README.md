# FoloToy AI Passport｜现代思维工具卡

> 把学过的 100 个思维工具装进口袋，随时翻一条，随时想起来。

## 项目介绍

我是一个得到用户，最近在学习万维钢老师的《现代思维工具课》100 讲。

课程学完之后，我一直在想一个问题：这些很有价值的概念，如果没有持续回顾，会不会过一段时间就忘了？

所以我把课程中的思维工具整理成一张张电子口袋卡片，并将它们放进 FoloToy AI Passport。它不需要打开手机、不需要连接网络，也不需要重新寻找课程章节。只要拿出设备、按一下按键，就能重新看到一个值得思考的概念。

这不是一台用来“刷内容”的设备，而是一个随身携带的学习提醒器：帮助自己反复提取、重新理解，并在真实生活中调用学过的知识。

## 它能做什么

- 内置 100 条思维工具概念，内容直接存储在设备 Flash 中。
- 完全离线运行，不依赖 Wi-Fi、手机或云端服务。
- 每张卡片包含序号、所属分类、概念名称和一句简要解释。
- 支持上一条、下一条和随机抽取。
- 自动记住上次看到的位置，重新开机后可以继续阅读。
- 开机先显示得到 logo，约 2.2 秒后进入思维工具卡片。

适合在通勤、等待、休息或需要做决定的时候，随手抽出一条重新思考。

## 按键说明

| 按键 | 操作 | 功能 |
| --- | --- | --- |
| 电源键 | 按住约 0.5 秒 | 开机 |
| 电源键 | 按住约 2 秒 | 关机 |
| `UP` | 短按 | 查看上一条；第 1 条继续向前会回到第 100 条 |
| `DOWN` | 短按 | 查看下一条；第 100 条继续向后会回到第 1 条 |
| `OK` | 短按 | 从 100 条内容中随机抽取另一条 |
| `OK` | 长按 | 进入“今日一条” |

屏幕熄灭后，可以通过功能键唤醒。当前阅读位置会写入 NVS，在设备重新启动后恢复。

> 当前版本的“今日一条”根据固件编译日期生成固定条目，还不是基于设备实时时钟的每日变化功能。

## 屏幕内容

设备使用 240 × 320 竖屏显示，每次只呈现一张卡片，减少干扰。

一张卡片主要包含：

1. 当前序号，例如 `9 / 100`；
2. 所属分类，例如“成长战略”；
3. 思维工具名称，例如“复利”；
4. 一句能够快速唤起记忆的解释；
5. 底部按键提示。

## 烧录方法

### 方法一：网页烧录

1. 打开 FoloToy AI Passport 网页烧录工具：<https://ai-passport.folotoy.cn/tools/web-flasher/>。
2. 使用 USB 连接设备。
3. 选择下载后的 `FoloToy-AI-Passport-full.bin`。
4. 将烧录地址设置为 `0x0`。
5. 开始烧录，等待写入和校验全部完成。
6. 设备重启后即可进入思维工具卡片。

网页工具只会在本地浏览器中把固件写入设备，不会上传固件文件。

### 方法二：使用 esptool

安装 `esptool`，确认设备串口后执行：

```bash
python -m esptool --chip esp32c3 --port /dev/cu.usbmodemXXXX --baud 460800 \
  write_flash 0x0 FoloToy-AI-Passport-full.bin
```

macOS 的串口通常类似 `/dev/cu.usbmodemXXXX`，Linux 通常类似 `/dev/ttyACM0`。部分新版 esptool 使用 `write-flash` 命令，此时将上面的 `write_flash` 替换为 `write-flash`。
